# <img src="docs/apple_logo.png" width="100" height="100" align="center"> Apple 웹사이트 클론 코딩

## 프로젝트 소개
Apple 웹사이트를 클론 코딩하여 기본적인 쇼핑몰 기능을 구현하고, 여기에 관리자 관점에서 필요한 매장/상품 관리 기능 등을 추가하여 실제 운영 가능한 웹 서비스로 확장했습니다.

## 기간
- 기간: 2024.10.01 ~ 2024.10.14 (2주)
- 인원: 5명

## 주요 기능
- **관리자 기능**
  - 상품 관리: 상품 등록/조회/수정/삭제
  - 매장 관리: 매장 등록/조회/수정/삭제
  - 배송 관리: 배송 조회/수정
  - 회원 관리

- **상품 관리 상세**
  - 상품 등록, 수정, 삭제 기능
  - 카테고리별 상품 정리
  - 할인 및 프로모션 설정

- **매장 관리 상세**
  - 오프라인 매장 등록 및 정보 수정
  - 매장별 재고 및 판매 관리
